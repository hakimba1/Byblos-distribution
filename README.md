# Byblos Distribution — site vitrine

Site carte de visite destiné aux fournisseurs (marques et fabricants). La vente se fait exclusivement sur Amazon.

Bilingue : français à la racine (`index.html`, `mentions-legales.html`), anglais dans `en/`. Toute modification de texte doit être faite dans les deux versions.

HTML/CSS statique, sans build ni dépendance.

## Voir le site en local

```bash
python3 -m http.server 8080
```
Puis ouvrir http://localhost:8080
